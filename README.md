# Privacy-Silhouette-Visualized
A tool to scan local caches and cookies to visualize your current privacy standing.


Set-up Process 

To begin please make sure you’re using chrome to use this tool. 

 
	First you will want to pull down the repository. After this please create a new folder, name it however you please. For this folder, please copy and place the following files into this folder 

	After this is done, go to Chrome and navigate to chrome://extensions/ and enable the Developer Mode slider on the far-right side. After this, on the far-left side, hit Load Unpacked. It will pop up a File Explorer window where you then must select that folder you created with those files in it. 

 

From here, you may then click the puzzle piece-shaped button on the top right to sift through your extension. Please select the extension titled “Local Privacy Score Analyzer”. Hit “Run Deep Analysis” and you’re done! Statics are displayed in a chart, and further statistics are available through a drop-down menu. ****
